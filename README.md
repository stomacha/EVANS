# EVANS

"자비스"라고 부르면 "Yes, Sir." 하고 대답하는 JARVIS 스타일 음성 비서 웹앱입니다.
정적 HTML 한 장(`index.html`)으로 동작하며, 폰 브라우저에서 바로 씁니다.

## 기능

- **호출어 감지** — 전원을 켜두면 마이크로 계속 듣다가 "자비스"를 감지하면 "Yes, Sir."로 응답
- **JARVIS 말투** — Claude가 영국 집사 톤의 영어로 짧게 대답하고 음성으로 읽어줌
- **한글 자막** — 화면 하단에 영어 원문(작게)과 한국어 번역 자막
- **자동 라우팅** — 요청 복잡도에 따라 Haiku 5.5 / Sonnet 5.5 / Opus 5.5 선택 (오른쪽 패널에 표시)
- **사용량 근황** — 오늘 요청 수, 입·출력 토큰, 추정 비용 (왼쪽 패널, 브라우저에 저장)
- **아크 리액터 UI** — 파란 리액터 주변을 상태 단어와 대답의 키워드가 공전

## 사용법

1. GitHub Pages로 공개하거나 `index.html`을 그냥 브라우저로 엽니다.
   - Pages: Settings → Pages → Branch `main` / root → Save
2. ⚙ 설정에서 **Anthropic API 키**를 입력하고 저장합니다.
   - 키는 이 브라우저의 `localStorage`에만 저장되고 폰에서 `api.anthropic.com`으로 직접 호출합니다.
   - 콘솔에서 지출 한도를 걸어둔 키를 쓰세요.
3. 오른쪽 위 **ON**을 켜고 마이크 권한을 허용합니다.
4. "자비스" → "Yes, Sir." → 질문을 말하면 영어로 대답하고 한글 자막이 뜹니다.
   - "자비스, 오늘 저녁 뭐 먹을까" 처럼 한 번에 말해도 됩니다.
5. 마이크를 못 쓰는 환경에서는 ⌨ 버튼으로 텍스트 입력을 쓸 수 있습니다.

## 라우팅 규칙

요청 길이, 절 개수, 키워드(코드·분석·설계·수학·작성·상세·추론·변환)로 복잡도 점수를 매깁니다.

| 점수 | 모델 |
| --- | --- |
| 0 ~ 1 | `claude-haiku-5-5` |
| 2 ~ 3 | `claude-sonnet-5-5` |
| 4 이상 | `claude-opus-5-5` |

설정에서 특정 모델로 고정할 수도 있습니다. Opus/Sonnet 요청에는 서버 측 refusal fallback(`fallbacks: "default"`)이 켜져 있습니다.

## 브라우저 참고

- 음성 인식은 Web Speech API를 씁니다. Android Chrome, iOS Safari 14.5+ 에서 동작합니다.
- iOS는 화면이 꺼지거나 다른 앱으로 가면 인식이 멈춥니다. 다시 돌아오면 자동으로 재개합니다.
- 영국식 남성 음성(Daniel 등)이 있으면 우선 사용하며, 설정에서 바꿀 수 있습니다.
